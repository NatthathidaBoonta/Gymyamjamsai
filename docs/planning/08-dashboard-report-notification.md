# Dashboard, Report, and Notifications: Gymyamjamsai

*(หมายเหตุ: เอกสารฉบับนี้ออกแบบขึ้นเพื่อตอบสนอง Requirement ของ **Gymyamjamsai** ตามที่คุณระบุ โดยได้นำคำศัพท์อย่าง "SLA Alert Rules" จาก Template เดิม มาประยุกต์ใช้เป็น "กฎการรักษาวินัยการออกกำลังกาย" เพื่อให้เกิดประโยชน์สูงสุดกับบริบทของแอปพลิเคชันสายสุขภาพครับ)*

---

## 1. Dashboard Cards (ข้อมูลสรุปแบบรวดเร็ว)
**สำหรับ Member (ประชาชน/นักศึกษา):**
- **Current Weight:** น้ำหนักปัจจุบัน พร้อมตัวเลข (+/-) เทียบกับสัปดาห์ที่แล้ว เพื่อให้เห็นแนวโน้มทันที
- **Current Streak:** จำนวนวันที่ล็อกอินเข้ามาออกกำลังกายต่อเนื่อง (สร้าง Gamification แรงจูงใจ)
- **Workouts This Month:** ยอดรวมจำนวนครั้งที่ออกกำลังกายในเดือนนี้
- **Next Activity:** นับถอยหลัง (Countdown) สู่คลาสกิจกรรมที่ลงทะเบียนไว้ครั้งถัดไป

**สำหรับ Admin / Trainer:**
- **Active Members:** จำนวนผู้ใช้งานที่มีความเคลื่อนไหวใน 7 วันที่ผ่านมา
- **Total Registrations:** ยอดรวมการลงทะเบียนคลาสกิจกรรมของสัปดาห์นี้
- **Average Attendance Rate:** อัตราเฉลี่ยการมาเข้าร่วมคลาสจริง (%)

## 2. Charts (กราฟสรุปพัฒนาการ)
- **Weight Progress (Line Chart):** กราฟเส้นแสดง "น้ำหนักจริง" (Actual Weight) เทียบกับเส้น "น้ำหนักเป้าหมาย" (Target Goal) ตลอดช่วงเวลา เพื่อให้ผู้ใช้/ผู้บริหารเห็นภาพรวมพัฒนาการ
- **Workout Frequency (Bar Chart):** กราฟแท่งแสดงความถี่การออกกำลังกายในแต่ละวัน/สัปดาห์ (ดูความสม่ำเสมอ)
- **Body Focus (Radar Chart):** กราฟใยแมงมุมแสดงสัดส่วนการบริหารกล้ามเนื้อ (เช่น แขน, ขา, อก, คาร์ดิโอ) เพื่อไม่ให้ผู้ใช้ออกกำลังกายส่วนใดส่วนหนึ่งหนักเกินไป

## 3. Tables (ตารางข้อมูล)
**3.1 ตารางแนะนำท่าออกกำลังกายวันนี้ (Today's Workout Plan)**
- *วัตถุประสงค์:* แสดงคิวท่าออกกำลังกายที่ระบบจัดมาให้ในวันนี้ (ตอบโจทย์ Requirement)
- *คอลัมน์:* 
  - ภาพตัวอย่างขนาดเล็ก (Thumbnail)
  - ชื่อท่า (Exercise Name)
  - ประเภทอุปกรณ์: **ออกที่บ้าน (Home) / อุปกรณ์ยิม (Gym)**
  - เป้าหมาย: เซต x จำนวนครั้ง (Sets x Reps)
  - **Action Button:** ปุ่ม `ดูรายละเอียด/วิดีโอสาธิต` (คลิกเพื่อเปิด Modal ดูวิธีทำที่ถูกต้อง)

**3.2 ตารางประวัติกิจกรรม (Activity History)**
- *วัตถุประสงค์:* สรุปรายชื่อคลาสที่เคยเข้าร่วมสำหรับนักศึกษา
- *คอลัมน์:* ชื่อคลาส, วันที่, สถานะ (เข้าเรียน / ขาด)

## 4. Filters (ตัวกรองข้อมูลบน Dashboard)
- **Date Range Picker:** กรองกราฟพัฒนาการตามช่วงเวลา (7 วัน, 30 วัน, ปีนี้)
- **Location Mode Toggle (Home / Gym):** สวิตช์สำหรับหน้า "ตารางออกกำลังกายวันนี้" เพื่อสลับให้ระบบคำนวณและแสดงท่าที่ใช้อุปกรณ์ยิม หรือท่าที่ใช้แค่น้ำหนักตัว (Bodyweight) สำหรับเล่นที่บ้าน
- **Activity Category:** กรองกราฟหรือตารางแยกตาม Cardo หรือ Weight Training

## 5. Report Export (การออกรายงาน)
- **Personal Progress Report (PDF):** ให้ Member ดาวน์โหลดใบสรุปผลประกอบการรายเดือน (กราฟน้ำหนัก + ท่าที่ทำไป) เป็นเหมือน "สมุดพกสุขภาพ"
- **Activity Attendance Report (CSV/Excel):** สำหรับ Admin หรือ Trainer ดาวน์โหลดรายชื่อนักศึกษาที่เข้าเรียนทั้งหมด เพื่อนำไปให้คะแนนหรือเทียบหน่วยกิตกิจกรรมของสาขาวิชา

## 6. Notification Rules (กฎการแจ้งเตือนคำแนะนำ)
- **Daily Workout Reminder:** แจ้งเตือนเวลา 08:00 น. หากวันนี้มีตาราง (เช่น "วันนี้ถึงคิวบริหารขา (Leg Day) แล้ว ลุยเลย!")
- **Smart Plan Adjusted:** ส่งแจ้งเตือนเมื่อระบบประมวลผลเปลี่ยนตาราง (เช่น "ระบบปรับตารางของคุณให้ท้าทายขึ้น 10% ตามพัฒนาการของคุณแล้ว")
- **Milestone Reached:** แสดงความยินดีเมื่อน้ำหนักขยับเข้าใกล้เป้าหมาย 50%, หรือทำ Streak ครบ 7 วัน

## 7. SLA Alert Rules (ประยุกต์เป็น: กฎรักษาวินัยการออกกำลังกาย)
ในบริบทฟิตเนส SLA (Service Level Agreement) คือกรอบเวลาที่ผู้ใช้ควรจะมีความต่อเนื่อง หากหลุดจากกรอบนี้ ระบบจะเข้าแทรกแซง (Intervention):
- **SLA ระดับ 1 (Warning - ขาด 3 วัน):** Member ไม่ได้ล็อกอินหรือบันทึกผลเกิน 3 วันที่มีตาราง -> ส่งแจ้งเตือน "หายไป 3 วันแล้วนะ ร่างกายต้องการการขยับเขยื้อน กลับมาทำเป้าหมายให้สำเร็จกันเถอะ!"
- **SLA ระดับ 2 (Critical - ขาด 7 วัน):** ไม่มีการเคลื่อนไหว 7 วัน -> สถานะแผนจะเปลี่ยนเป็น `Freeze` (แช่แข็งตาราง) เมื่อผู้ใช้กลับเข้าแอป ระบบจะขึ้นหน้าจอให้ทบทวนเป้าหมาย (ทำแบบสอบถามว่าป่วย/เจ็บ หรือยุ่ง) เพื่อให้ระบบ **ปรับลดตารางลงเป็น Recovery Mode** กันผู้ใช้ท้อ
- **SLA ระดับกิจกรรม (Class Risk สำหรับ Trainer):** หากคลาสมีคนลงทะเบียนไม่ถึง 30% เมื่อเหลือเวลา 24 ชม. ก่อนเริ่ม -> ส่ง Alert ให้อาจารย์/Trainer เพื่อพิจารณาโปรโมทคลาสหรือยุบรวมคลาส

## 8. ตัวอย่างข้อมูลที่ใช้คำนวณแต่ละตัวชี้วัด (Calculation Metrics)
- **BMI (Body Mass Index):** `น้ำหนัก (กก.) / [ส่วนสูง (เมตร) ^ 2]`
- **Workout Plan Progress (%):** `(จำนวนท่าที่บันทึกว่าทำเสร็จในสัปดาห์ / จำนวนท่าทั้งหมดในแผน) * 100` (ใช้ประเมินความสม่ำเสมอ)
- **Weight Goal Progress (%):** `(|น้ำหนักเริ่มต้น - น้ำหนักปัจจุบัน|) / (|น้ำหนักเริ่มต้น - น้ำหนักเป้าหมาย|) * 100` *(ใช้ Absolute | | เพื่อให้สมการรองรับทั้งคนที่ต้องการลดไขมัน และเพิ่มมวลกล้ามเนื้อ)*
- **Attendance Rate (%):** `(จำนวนคนที่ Trainer เช็คชื่อว่ามาจริง / จำนวนคนที่กดลงทะเบียนทั้งหมด) * 100`
