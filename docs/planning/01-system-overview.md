# System Overview: Gymyamjamsai (ระบบติดตามพัฒนาการการออกกำลังกายออนไลน์)

## 1. Executive Summary (บทสรุปผู้บริหาร)
Gymyamjamsai เป็นเว็บแอปพลิเคชันที่ผสมผสานระหว่าง **ระบบติดตามพัฒนาการการออกกำลังกายส่วนบุคคล** และ **ระบบจัดการกิจกรรม/คลาสของสาขาวิชา** เพื่อตอบสนองความต้องการของผู้ใช้ที่ต้องการดูแลสุขภาพอย่างเป็นระบบ ควบคู่ไปกับการเข้าร่วมกิจกรรมขององค์กร โดยระบบจะช่วยตั้งแต่การประเมินร่างกายเบื้องต้น (Onboarding) การสร้างตารางออกกำลังกาย การบันทึกผล ไปจนถึงการวิเคราะห์พัฒนาการผ่าน Dashboard นอกจากนี้ยังรองรับการจัดการกิจกรรมที่เปิดให้ลงทะเบียนเข้าร่วม เช่น คลาสออกกำลังกายกลุ่ม หรือกิจกรรมพิเศษของสาขาวิชา 

*(หมายเหตุ: ระบบได้บูรณาการ Requirement ทั้งส่วนของการติดตามพัฒนาการการออกกำลังกาย และส่วนของระบบลงทะเบียนกิจกรรมสาขาวิชาเข้าด้วยกัน เพื่อให้เป็นระบบศูนย์กลางแบบ All-in-One)*

## 2. Project Objectives (วัตถุประสงค์ของโครงการ)
1. **Personalized Fitness Tracking:** เพื่อให้ผู้ใช้สามารถติดตามข้อมูลร่างกาย ตั้งเป้าหมาย และรับคำแนะนำตารางการออกกำลังกายที่เหมาะสมกับตนเอง
2. **Progress Analytics:** เพื่อให้ผู้ใช้เห็นภาพรวมพัฒนาการของตนเองผ่าน Dashboard และกราฟที่เข้าใจง่าย ช่วยสร้างแรงจูงใจในการออกกำลังกาย
3. **Activity Management:** เพื่อให้ผู้สอน/อาจารย์ สามารถสร้างกิจกรรมหรือคลาส และให้นักศึกษา/ผู้ใช้ สามารถดูรายละเอียดและลงทะเบียนเข้าร่วมได้อย่างสะดวก
4. **Centralized Administration:** เพื่อให้ผู้ดูแลระบบสามารถจัดการข้อมูลผู้ใช้ ตรวจสอบสถิติการใช้งาน และสรุปรายงานผลการจัดกิจกรรมต่างๆ ได้อย่างมีประสิทธิภาพ

## 3. User Roles & Target Audience (กลุ่มผู้ใช้งาน)
ระบบถูกออกแบบมาเพื่อรองรับผู้ใช้งาน 3 กลุ่มหลัก ดังนี้:

1. **Member / Student (สมาชิก / นักศึกษา)**
   - ลงทะเบียนและจัดการข้อมูลส่วนตัวเบื้องต้น (น้ำหนัก, ส่วนสูง, เป้าหมาย)
   - ดูและปฏิบัติตามตารางการออกกำลังกายที่ระบบแนะนำ หรือบันทึกผลการออกกำลังกายด้วยตนเอง
   - ดู Dashboard สรุปพัฒนาการของตนเอง (กราฟน้ำหนัก, สถิติการออกกำลังกาย)
   - ดูรายการกิจกรรมของสาขาวิชา/คลาสออกกำลังกาย และกดลงทะเบียนเข้าร่วม

2. **Trainer / Teacher (ผู้สอน / อาจารย์)**
   - สร้างและจัดการกิจกรรม (กำหนดชื่อกิจกรรม, วันเวลา, สถานที่, และกำหนดจำนวนรับสมัครสูงสุด)
   - ตรวจสอบรายชื่อนักศึกษาที่ลงทะเบียนเข้าร่วมกิจกรรม
   - จัดการสถานะการเข้าร่วมกิจกรรม (Attendance)

3. **Administrator (ผู้ดูแลระบบ)**
   - จัดการข้อมูลผู้ใช้งานทั้งหมดในระบบ (ดู, แก้ไข, ระงับสิทธิ์)
   - ดู Dashboard สรุปภาพรวมของระบบ เช่น จำนวนผู้ใช้งานทั้งหมด, สถิติการเข้าร่วมกิจกรรม
   - พิมพ์/Export รายงานสรุปจำนวนผู้เข้าร่วมกิจกรรมเพื่อนำไปใช้งานต่อ

## 4. Key Features (ฟีเจอร์หลักของระบบ)

### 4.1 Onboarding & Goal Setting
- หน้าจอสอบถามข้อมูลพื้นฐานเมื่อเข้าใช้งานครั้งแรก (น้ำหนัก, ส่วนสูง, เป้าหมายเช่น ลดน้ำหนัก/เพิ่มกล้ามเนื้อ)
- การคำนวณค่าพื้นฐาน เช่น BMI เพื่อเป็นข้อมูลตั้งต้น

### 4.2 Workout Management & Tracking
- **Smart Workout Plan:** ระบบแนะนำตารางการออกกำลังกายเบื้องต้น และรองรับการปรับตารางอัตโนมัติตามพัฒนาการ
- **Exercise Library & Logging:** ข้อมูลท่าออกกำลังกาย และระบบบันทึกผลการออกกำลังกายในแต่ละวัน

### 4.3 Activity Registration System
- **Event Catalog:** หน้ารายการกิจกรรมทั้งหมดที่กำลังจะเกิดขึ้น พร้อมแสดงจำนวนที่นั่งว่าง/เต็ม
- **Booking System:** ระบบกดลงทะเบียนเข้าร่วมกิจกรรมสำหรับนักศึกษา
- **Participant Management:** หน้ารายชื่อผู้เข้าร่วมสำหรับอาจารย์เพื่อตรวจสอบและจัดการ

### 4.4 Analytics & Dashboard
- **Personal Dashboard:** กราฟแสดงการเปลี่ยนแปลงของร่างกาย และความสม่ำเสมอในการออกกำลังกายสำหรับนักศึกษา
- **Admin/Teacher Dashboard:** รายงานและกราฟสรุปภาพรวมกิจกรรมและผู้ใช้งานในระบบ

## 5. Technology Stack Overview (ภาพรวมเทคโนโลยี)
*ตามข้อกำหนดสำหรับการพัฒนาและการ Deploy*

- **Frontend:** React 18 + Vite 5 + CSS (Vanilla)
- **Backend:** Node.js 20 LTS + Express 4
- **Database:** MySQL 8
- **Development Environment:** Docker Compose (รวม App, Database และ phpMyAdmin สำหรับจัดการ DB)
- **Deployment:** Railway (Single-container deployment ผ่าน Dockerfile multi-stage โดยไม่ใช้ Nginx แยก)
